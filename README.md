# Work Pro

A decentralized freelance marketplace built on Pi Network. Connect clients with freelancers, manage projects with escrow payments, and build trust through reviews — all powered by Pi cryptocurrency.

## Features

- **Job Marketplace** — Post jobs, browse listings, apply with connects
- **Escrow Payments** — Secure Pi-funded escrow with release on completion
- **In-App Chat** — Real-time messaging between clients and freelancers
- **Reviews & Ratings** — Build reputation with post-project reviews
- **Connects System** — Purchase connects with Pi to apply for jobs
- **Admin Dashboard** — Full analytics and management panel

## Pi Network Integration

- Pi Authentication SDK v2.0
- Pi Payments API for in-app purchases
- Sandbox + Production modes
- Pi Browser optimized

## Tech Stack

- Frontend: React + Vite (GitHub Pages)
- Backend: Node.js + Express + SQLite (Render)
- Payment: Pi Network SDK + API
