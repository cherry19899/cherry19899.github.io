Description (copy for develop.pi)

Work Pro is a decentralized freelance marketplace built on Pi Network. 

Clients can post jobs, freelancers can apply using connects, and payments are secured through Pi-funded escrow. Features include real-time chat, reviews, admin dashboard, and Pi SDK integration.

Key features:
- Post and browse freelance jobs
- Apply with connects (purchased via Pi)
- Escrow payments in Pi cryptocurrency
- In-app chat between clients and freelancers
- Review and rating system
- Admin analytics dashboard

Built with React, Node.js, SQLite, and Pi Network SDK.

SDK Configuration

// Already configured in the app:
Pi.init({
  version: "2.0",
  sandbox: true
});

Pi.authenticate(["username", "payments"], onSuccess, onError);

Pi.createPayment({
  amount: 1.0,
  memo: "Buy 10 Connects",
  metadata: { package_amount: 10 }
}, onReady, onCancel, onError);
Note: Set sandbox: false for production after app is approved.
